Платформа для волонтерів допомагає організаціям знаходити учасників для заходів. 

Особливості мого проекту:
- Організації можуть реєструватися та публікувати волонтерські завдання й заходи.
- Розширені фільтри для пошуку заходів, спілок і користувачів.
- Волонтери обирають заходи, де хочуть допомогти.
- Можливість залишати відгуки та оцінювати участь у заходах, що підвищує прозорість і якість роботи.
- Використання JWT і Spring Security для захисту персональних даних.


A volunteer platform helps organizations find participants for events.

Project features:
- Organizations can register and post volunteer tasks and events.
- Advanced filters for searching events, groups, and users.
- Volunteers choose the events where they want to help.
- Ability to leave reviews and rate participation in events, enhancing transparency and work quality.
- Use of JWT and Spring Security to protect personal data.
